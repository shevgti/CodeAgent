# Личный харнес

Харнес живёт в текущем SheVagent и состоит из четырёх частей:

1. `src/loop.mjs` — цикл: модель -> инструмент -> результат -> финальный ответ.
2. `Skills` — каталог навыков. Свои навыки клади в `data/learned-skills`, подтянутые из GitHub — в `data/github-skills`.
3. `Tools` — статические инструменты плюс динамический каталог `find_tools`/`load_tool`.
4. `src/eval-live.mjs` — проверка, что изменение действительно улучшило решение задачи.

## Типовой цикл работы с проблемой

- Сформулируй проблему одной фразой и назови измеримый признак успеха.
- Найди подходящий навык: `find_skills` по ключевым словам задачи.
- Найди инструмент: `find_tools`, затем `load_tool`.
- Выполни действие и проверь результат тем же инструментом, который умеет измерять (тест, статус, diff).
- Если приём сработал, сохрани его через `learn_skill` в `data/learned-skills`, чтобы не повторять поиск.

## GitHub как источник

Репозиторий подключается командой `github_sync` с публичным URL вида
`https://github.com/owner/repo`. Из него берутся `skills/*/SKILL.md` и
`tools/manifest.json`. Манифест может только объявлять алиасы на уже
разрешённые инструменты — произвольный код не запускается.

После `github_sync` навыки доступны как `gh-<repo>-<id>`, алиасы — через `find_tools`.
