# CodeAgent — личный харнес SheVagent

Репозиторий — источник инструментов и навыков для локального агента SheVagent.
Агент подтягивает его командой `github_sync`, после чего навыки становятся
доступны через `find_skills` / `load_skill`, а алиасы — через `find_tools` / `load_tool`.

## Структура

- `skills/<id>/SKILL.md` — навык в формате SheVagent (frontmatter `name`/`description` + инструкция).
- `tools/manifest.json` — только алиасы на уже разрешённые агентом инструменты.
  Произвольный код из репозитория не исполняется.

## Правила

- Никаких API-ключей и облачных сервисов.
- Приватные репозитории и запись в GitHub — только по явной просьбе и с токеном.
- `CHECK:` от unlazy не одобряется автоматически.
